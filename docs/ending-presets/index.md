# Ending 方案库

记录用户认可的结尾效果，供 agent 按剧情选用；不是全剧统一模板，也不代表
任意 EP 都已有一键渲染能力。没有适合的方案时提出新方案，不强套已有特效。

## 选用与扩展

1. agent 先依据实际末镜、剧情落点和已确认风格选择方案，在创作计划与
   渲染 manifest 记录 `ending_preset_id`、`ending_preset_version` 和参数覆盖。
   这些是记录约定，不是现有 runner 自动消费的字段。
2. 套用的是效果结构和相对时序，不是样片的绝对集号、时码、人物、音乐、
   响度测量或画面内容。动作/最后一句先完成，再进入有意定格或转场。
3. 渲染前检查实现支持，渲染后检查实际效果与音效落点；保留新版本目录、
   原片和旧版。概念认可、完整 EP 审核及发布批准分别记录。
4. 用户提出新效果时新增独立 ID；同一效果的可复用结构发生变化时新增
   版本文件，不覆盖已认可版本。一次性强弱/时长修改可记在该次 manifest
   的参数覆盖中，不能反向篡改库内基准。
5. 每个新条目至少记录：名称/ID/版本、适用与不适用场景、相对时序、
   画面/声音参数、预览及 SHA256、实现入口、验收范围、素材来源和用户反馈。
   有实现但未验收的标记为候选，不混入“用户认可”列表。

本库只登记方案；不会因入库自动替换任何 EP、触发采购/补生成或发布。
