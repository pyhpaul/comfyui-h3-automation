# L2 — 说话人 / 同镜口型全检

完整方法论见：`docs/ops/2026-10-21-speaker-attribution-audit-v2.md`。本文件只定与本 skill 的衔接。

## 触发与范围

- **触发**：L0（或升层）得到的 `HIGH_RISK_CHORUS` 镜头。
- **定案范围**：**该 U 的全部对白句**，不是只审触发镜。
- HIGH 镜头用于定位优先段与写工单；单镜实看**不能**单独给候选 `STRICT`。

## 能力门

须能对 mp4 **连续播放并带声试听**。否则 L2 = `NOT_DONE` / `SCREENING_DONE_WATCH_INCOMPLETE`，
结案保留「说话人未定案」。
仅 ASR / 静帧 / F0 证据偏弱，有播放条件时应做带声实看；最终成片仍走人审。

## 自动筛查算力

批量 ASR / 词级时间戳 / 密帧导航优先用**本机 GPU**（见 skill「算力（GPU）」）。
禁止占用正在出片的租卡 Comfy。GPU 筛查与 CPU `audit_candidate` 可并行，产物分目录；
**筛查完成 ≠ 说话人定案**。

## 逐句证据与覆盖

- 先用参考设定/已确认素材锁身份；无法辨认不按服装或音高硬猜。
- 全 U 先看一次，再逐句前后至少 0.5 秒连续带声复核（边界限于源时长）。
- 清单以剧本台词为全集；合句拆句用多对多对齐，不按 ASR 段数组下标配期望台词。
  未转写到的句子仍待审；额外发声区间单列，不挤占下一句的位置。
- 每句记录期望说话人/发声类型、实际音画证据、其他可见嘴部、完整性、顺序、可验证性。
  听者的表情/呼吸或单张开口帧不能证明同念；音高不能证明人物身份。
- `inner_os` / `phone_os` / `offscreen` 单独验证声轨和画面语义，不因未见嘴部而报错。
  也不把这类句子记作已证明某个画外人物的口型正确。
- 分别统计期望句数、已定位数、模型复核数、人工完整实看数、不可验数；无连续音画输入的
  agent 应把人工实看数记 0。能生成播放器页面不代表自己看过。
- 原片和证据保存在项目目录；全帧上下文优先，局部嘴部 crop 仅辅助，不丢失其它可见嘴部。

模型音画复核先过能力探针和坏例/正常对照校准；模型建议与人工 V2 分文件保存。
未实现或未通过校准时保持 `NOT_DONE` / `SCREENING_DONE_WATCH_INCOMPLETE`。
模型结果不能伪装为 `full-dialogue-watch` 人工签字，不能绕过 `fix_registry` 现有证据门。
建设方案见 `docs/ops/2026-10-23-unit-av-review-implementation-design.md`。

## 与复修 V2 的关系

| | 本 skill 批次 QC | fix_registry 候选定案 |
|---|---|---|
| 谁触发全检 | L0/升层 HIGH → 整 U 对白 | 凡要 STRICT/RELAXED 的候选 |
| 正反打等 | 含在该 U 全句实看内 | V2 原文高风险条全适用 |
| L0 未命中 | 不默认强制 L2 | **仍须**完整 V2，不得减免 |

## P1

不执行 L2 定案。计划中层状态写 `L2: NOT_STARTED`，顶栏「说话人未定案」。
