# L3 — 可选穿帮筛查

## 状态接口（必填于 plan/report）

| 状态 | 含义 |
|---|---|
| `NOT_RUN` | 默认；未做穿帮检查 |
| `RUNNING` | 抽帧/模型进行中 |
| `SUSPECTS_OPEN` | 有未确认嫌疑 |
| `SCREENED_NO_SUSPECTS` | 声明范围内完成筛查、未列嫌疑；不表示全片人工排除穿帮 |
| `CLEARED_BY_HUMAN` | 嫌疑已人工关闭或确认无穿帮 |

P1–P3 默认 **`NOT_RUN`**。不引入强制每秒抽帧全量流程。

## 原则

- 自动只出 `SUSPECT` + 时码 + 帧路径；人确认后才进缺陷单。
- 自动嫌疑可供分流；确认缺陷后再开复修。不自动重渲。
- 未执行时写明「穿帮未检查」。

## 双通道试点

用户要求 L3 时，两条通道都考虑，不能只检查其中一条便声称全维度完成：

- 局部形体：手指、手臂归属、遮挡处融合、持物接触。全片稀疏帧筛查，疑似处增加原分辨率
  帧与邻近时间导航；单帧不能区分运动模糊、正常双手和真实多肢体。
- 连续性/剧本约束：人物身份、服装穿戴、道具交接、应在画外却入画等。区分生成错误、
  省略动作和可接受的构图偏离；不能把所有偏离都归成必须重渲。

记录源 hash、实际检查 U、抽帧间隔/数量、实际查看范围、未检查范围。
「已生成 246 张」不等于「已查看 246 张」；缩略拼图不能支撑细指节排除结论。
每个嫌疑保留时段、原帧路径、人物/部位、预期与观察、替代解释、下一步连续回放范围。
局部 crop 只能作为原帧的派生证据，不覆盖原帧。多个 agent 的嫌疑合并去重，保留来源，
未列单不等于对另一个 agent 的嫌疑投反对票。

模型辅助时还须区分「可见成片异常 / 剧本执行偏差 / 分辨率或遮挡不可验」。
缩略图上看不见戒指、衣服或文字，不能作为它们缺失的阳性证据。
自由列单可能漏掉明确的画外约束：对已脱外套、不得入画、交接持物等另设核对项。
两阶段执行和预算外未复核项见 [CLI 视觉筛查](cli-visual-screen.md)。
