# EP03 / EP04 → YZ H3 unit jobs

**本文范围：** 仅 **EP03 / EP04** 扁平上传参考包 → 模板 `yz_h3_ep_unit`（不描述 EP02）。

## 包布局（EP03 / EP04）

```text
EPxx/
  upload-manifest.json
  control/Uxx-director-control.png
  previz/Uxx-colour-blockout.webm
  prompts/Uxx.txt
  assets/{characters,scenes,props}/...
```

- **EP03**：`units[].upload_order` + `control_reference` / `previz_reference` + `duration_seconds`
- **EP04**：manifest 常只有 control/previz/prompt；身份顺序从 `prompts/Uxx.txt` 的「本 U 实际上传顺序」解析；时长从标题行解析（如 `｜10 秒`）

## YZ 槽位映射

| Job 字段 | H3 / 节点 | 来源 |
|---|---|---|
| `ref_image_0` | 控制图（图像1） | control |
| `ref_image_1..N` | 身份参考（图像2…） | upload_order 去掉 control/previz；**按实际张数，不垫重复**；超过 5 张截断 |
| `ref_video_0` | 参考视频1 | previz webm（包内通常仅 1 条；模板另有视频2/3 会 Never 并断开） |
| `prompt` | 提示词 | EP 原文经 `h3_prompt.build_h3_r2v_prompt` 转成 H3 六段英文（`<Picture>/<Video>/<Subject>` 与 YZ 槽位一致）；原文落 `assets/prompt_source.txt` |
| `duration_seconds` | 时长 | manifest 或 prompt |
| `aspect_ratio` | 分辨率 | 固定 `9:16 (Portrait Widescreen)` |

未使用的 LoadImage 在 UI 导出中设为 **Never** 并断开 H3 对应口。

## 生成 job

```bash
python scripts/ep_pack_to_jobs.py /path/to/EP03 /path/to/EP04 -o jobs/ep_units
# 或只生成若干 U
python scripts/ep_pack_to_jobs.py /path/to/EP03 -o jobs/ep_units --unit U01 --unit U02
```

产出：`jobs/ep_units/EP03-U01/`（含 `job.yaml` + `assets/`）。

## 在 Comfy UI 里查看「填槽效果」（不入队）

`/prompt` 不会回填画布。要看控件/缩略图：先上传素材，再 Load 绑定后的 API JSON。

```bash
export COMFY_BASE_URL=http://192.168.5.122:8190   # 经 vm122 转发到租卡
python scripts/ep_pack_to_jobs.py /path/to/EP03 -o /tmp/ep_jobs --unit U01
python scripts/export_bound_workflow.py /tmp/ep_jobs/EP03-U01 \
  -o "/mnt/c/Users/lxy/Downloads/EP03-U01-yz-bound-api.json" \
  --out-ui "/mnt/c/Users/lxy/Downloads/EP03-U01-yz-bound-ui.json"
```

比对布局请用 **UI Format**（保留原 YZ 坐标/分组；只改槽位控件）：

`C:\Users\lxy\Downloads\EP03-U01-yz-bound-ui.json`

浏览器打开同一 Comfy → **Load** 该 UI JSON → 检查 图像1–6 / 参考视频1 / 提示词 / 时长。  
API JSON 仅作执行图备份，Load 后会重排，不适合肉眼比对。  
**先不要 Queue** 整图 H3，除非刻意试跑。

## 提交出片（租卡 GPU + 隧道）

需远端已装齐 YZ 图所需自定义节点与 H3 权重；`COMFY_BASE_URL` 指向可达的 Comfy API。

```bash
export COMFY_BASE_URL=http://192.168.5.122:8190
comfy-orch submit /tmp/ep_jobs/EP03-U01
```

完整 H3 出片耗时长；编排默认 5090 串行，弱卡不进本期。
