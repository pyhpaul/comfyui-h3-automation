# Agent 主导结尾与音乐创作

本项目默认由 agent 先判断并制作推荐版，用户审片后再决定是否调整。
[Ending 方案库](../../../../docs/ending-presets/index.md) 保存已认可的可选效果；
新要求可追加独立方案/版本，不覆盖已有认可，也不把一个例子设为全剧默认。
本文件定义创作和审查流程，不表示 EP01 runner 已支持全部效果。
v3 已实现轻推近、受保护区间、逐 cue 增益与淡化；虚影、背景柔化、
独立 SFX 轨、多曲署名与交付仍未完备，选用前按实际能力适配。

## 1. 从素材到决策，不先让用户选菜单

1. 阅读 EP 剧情预期、分镜、台词、交出状态，检查实际顺序画面与声音；
   明确最后一个信息揭露、角色选择和仍未解决的问题。
2. 将本集分成少量叙事节拍，记录时段、事件、观众应感受到的情绪、
   强度与留白需求。不能只见“争吵”就配强节奏音乐。
3. 结合既有风格、可用音乐/SFX 与画面余量，agent 自行比较少量候选，
   选择一套有依据的方案。通常只交一版推荐成片，不默认批量生成 A/B。
4. 检查计划能否被现有入口实际执行；缺功能先做最小适配和回归验证。
   明确受限时可制作保守可运行版本，并披露舍弃了什么，不能假装实现。
5. 完成渲染与 QC，让独立 agent 审核实际成片；处理阻断项后交用户。
   对非阻断审美分歧给出推荐理由，不无限反复试剪，也不掩盖不确定性。

“最适合”是当前素材、风格与检查证据下的推荐，不是客观唯一最优。
只有抽帧/信号分析时，不声称已经完整观影或试听确认。

## 2. 结尾选择

| 剧情落点 | 候选画面 | 候选声音 |
|---|---|---|
| 身份揭露、突然反转 | 保留反应、轻推近、短入黑 | 克制重音，随后短留白 |
| 威胁、危险逼近 | 缓推或渐暗，不提前切掉线索 | 氛围增强，在悬点收断或延音 |
| 人物选择、平静反击 | 动作完整，最终眼神停留后淡出 | 音乐落点与延音，不强上惊吓声 |
| 悲伤、关系破裂 | 保留停顿和眼神、柔和淡出 | 克制延音或撤掉音乐保留现场声 |

上表是候选，不是分类后的强制效果。agent 可决定不加推近或音效，
但应说明为什么原表演/原声更有效；也可以组合少量互不冲突的处理。

- 轻推近可从约 1-1.5s 内 100% 到 103%-105% 试起，须根据构图、
  运动与源分辨率调整；不裁掉关键动作、不出现边缘露底或突然跳尺度。
  用户已反馈本例 3.5% 不易察觉，因此需检查实际可感知度；本例 v4
  提至 10% / 2s，不能将“滤镜执行了”等同于“观众看得见”。
- 优先保留运动素材，不为制造悬念默认冻结/拉长人脸。没有反应余量时
  用现有有效落点，不能凭空改变演员表情或剧情。
- 渐暗/背景柔化不能吞掉最后线索；分离边缘不可靠就不用背景特效。
- 虚影仅用于回忆、眩晕、冲击等有明确剧情依据的主观表达；默认不选，
  但不一刀切禁止。不能拿重影盖拼接错误，不能对对白字幕叠出残影。
- 音效点对准实际揭露或反应，不机械放在最后一帧；可用轻低频、短上升、
  收断或原声留白，不能盖最后一句。音乐已有有效重音时不再堆同类 SFX。
- 保留尾卡作为当前视觉基线，卡长和入黑节奏可在剧情依据下调整；
  预留足够看清主文案的时间，不以加长尾卡代替完成最后动作。

v21 EP01 的推荐方向是平静反击：保护系鞋带和最终反应，再考虑轻推近
及克制声音收束；v3 据此制作，既有 v2 不含推近。每次是否通过仍以对应
实际成片和审核证据为准，不能仅凭方向说明判定。

## 3. 音乐随剧情推进

- 从许可明确的可用资产选择；不因需要变化就自动采购、下载或补生成。
  缺少合适音乐时先完成能成立的原声/单曲推荐版，并报告资产缺口。
- 优先一个主题的不同段落、强弱或已具备的分轨，保持人物与整集身份。
  当剧情出现明确情绪转向时可换不同曲目，不设“必须几首”的配额。
- 比较候选的情绪、音色、节奏密度、对白频段占用、强度走向与结束方式；
  换曲考虑乐句、调性与节奏兼容，不只靠自动交叉淡化。
- 揭露前可撤掉音乐，揭露后再进入；升级不等于持续变响，留白也是决策。
- 音乐进入、段落变化、退出都对齐实际剪辑后的时间轴。源曲换段/换曲、
  重排或加 SFX 后，重做样本域落点、残差、响度和最终 AAC 核对。
- 沿用对白避让，但不靠全程强 ducking 挽救过满编曲；先选择更适合对白
  的素材与段落。独立音效轨也应接受字头字尾与峰值检查。

## 4. 决策记录与可修改性

在任务输出目录保存 `creative_plan.json`，并在实际 manifest 中关联它；
它是新增的创作记录约定，现有 runner 不会自动读取或执行此文件。
至少记录：

- 本集情绪目标、结尾悬点、叙事节拍及其时段、受保护动作。
- 推荐结尾镜头/区间、效果/音效、选择理由、未选方案及关键风险。
- 各音乐 cue 的曲目/文件 hash、源入点、成片入出点、情绪/强度、
  增益/避让、转接方式与授权依据。
- 每个效果的 `planned` / `rendered` / `verified` 状态，实际实现位置和参数；
  尚未支持或被放弃的项明确写出，不能当作已交付。
- 版本、审核意见、人工可改项、对应的参数/区间和重新验证范围。

给用户的是“一版推荐成片 + 简短创作说明 + 剩余风险”，不是待填参数表。
用户可说“推近少一点”“结尾更有压迫感”“后半段换音乐”；agent 负责将
意图落实到参数与 cue，保留旧版后重渲并复核，不要求用户懂滤镜或混音。

## 5. 自主执行边界

常规创意判断无需逐项批准。剧情/源文件缺失、许可不明、额外费用、
补生成、修改原始对白/故事事实、外部发布等实质问题，才提交明确决策点。
技术未支持时能在当前开发范围内适配就继续；不能安全完成就说明缺口，
不能默默用错误脚本顶上，也不把权限范围扩大为任何外部操作。
