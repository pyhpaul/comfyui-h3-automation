# Episode Assembly / Post-production

将一个 EP 的定版单元做成可审阅的完整一集；不把“拼接成功”等同于
“剧情完整”或“可以发布”。先锁素材和剪辑计划，再渲染、QC、审核。

## 选择入口

| 任务 | 入口 / 必读资料 |
|---|---|
| 完整后期、字幕/BGM/尾卡、试片复现 | [完整后期与试片复现](references/post-production.md) |
| agent 自主选择结尾效果、音效、剧情节拍配乐 | [Agent 主导创作](references/agent-direction.md) |
| 选用已认可 ending，或记录新方案 | [Ending 方案库](../../../docs/ending-presets/index.md) |
| 接缝诊断、计划粗剪 | 本文件的剪辑和接缝规则 |
| 成片验收、自检、按需独立审核、交付 | [QC 与审核](references/qc-review.md) |

### 当前实现边界

- 旧研究分支的 `scripts/assemble_episode.py` 是粗剪实验工具，不是本次
  归档的执行依赖，也不是完整后期入口。
  它会按末词裁尾、可能误判说话人并强制跳头；没有 BGM、尾卡、字幕
  烧录和完整 QC。**不要直接用它生成可交付版。**
- 正式试片入口为项目内 `scripts/episode_post/run_ep_post_pilot.py`，
  读取已审剪辑 manifest，输出母版、烧字幕审片版、音乐和技术报告。
  它仍限定 EP01、英文、768x1376 / 24 fps、固定尾卡与音频参数，
  不是任意 EP 的通用 CLI。完整路径、命令和限制见后期参考。
- 本 skill 是执行规程，不会通过文字更新自动修复上述程序。
  新 EP 必须先核实入口能力，缺少能力就明确实施适配；不能只改
  `episode` 字段后声称通用化，也不能悄悄回退到旧粗剪器。
- 已认可样片及许可/审核在 `assets/episode_post/`；代码、测试和资产
  不再依赖研究 worktree。环境及私有源片恢复见 `scripts/episode_post/README.md`。

## 已选试片风格：可复用起点，不是全剧强制规范

用户已选沉浸式剧情风格：对白、表演、动作优先，避免包装抢戏。

- 英文语义短句字幕 + 对齐时间轴的中文词轨（`zh.srt`/`zh.ass`）；不做逐词跳动；
  另出烧英文字幕审片版。计划须带 `zh_captions`。
- 稀疏 BGM，仅在揭示、情绪转折和结尾使用；对白区降低配乐，允许留白。
  **母版 `*-master.mp4` 不含配乐**（对白+结尾 SFX）；BGM 只进审片版。
- 剧情内优先干净硬切；J/L cut 按具体接缝决定，不默认每缝套用。
- 保留最终动作和反应，短淡出后接深色暖白衬线
  `TO BE CONTINUED` 尾卡；试片卡长 1.25s，不加长片尾字幕。
- 按最新反馈，尾卡不烧录音乐署名小字；完整授权信息留在附件与发布说明。
  结尾动画要在正常播放中可感知，不能只验证滤镜存在。v3/v4 的纯推近
  未达到用户预期；已认可“泛光柔焦＋额外定格 1 秒＋悬疑音效”概念，
  见方案库 `bloom-hold-suspense` v1，不再仅靠增加 zoom 模仿该效果。
- 试片保持原生 768x1376 / 24 fps、48 kHz 音频；整集目标
  -16 LUFS / -1.5 dBTP。平台另有要求时单独确认，不当作行业标准。
- 不自动新增片头、剧名翻译、花哨转场、音乐采购或补生成镜头。

新剧的情绪与风格由 agent 根据内容先提出并落实推荐方案，不要求用户
逐项选参数；平台交付规格缺失且影响制作时才确认，不重问已确定的选择。

## 默认协作模式：Agent 先做推荐版，人工后调整

用户希望由 agent 主导结尾与音乐的创作判断。先读实际素材和剧情，
自行决定效果、配乐段落、切换与留白，生成一版最有依据的推荐成片，
经执行 agent 自检和技术 QC 后交用户；默认不启动子 agent 审核。
不先发参数菜单等待人工选定，也不默认批量渲染
多个版本让用户代做判断。“审过的计划”默认指 agent 自检，非人工审批。

结尾可选轻推近、渐暗/淡出、虚影或同步音效，配乐可按剧情阶段选择
不同段落/曲目；是否使用、使用多强由剧情和实际素材决定，不为炫技叠加。
完整决策规则见 [Agent 主导创作](references/agent-direction.md)。
先查方案库再按剧情选择，记录方案 ID/版本与本次覆盖参数；库内方案不强制
用于所有集。选用具体方案后，其时序优先于旧试片的通用淡出基线。

首版在现有可用且许可明确的素材、原有剧情和技术能力内自主推进；
不改变对白与故事事实、不自动采购、补生成或发布。存在能力缺口时先
适配并验证，不把计划字段当作已生效效果。人工在审片后可直接提出
“结尾更克制”“音乐更紧张”等修改，agent 负责转换为具体改点和重渲。

## 工作流

### 1. 锁定素材与依据

- 列出预期 U、剧情顺序、版本、候选选择和源文件 SHA256；不能递归
  找到第一条 mp4 就选用。缺条、多候选、混版本时先解决歧义。
- 核对 prompt、run_meta、词轨/审核缓存及其源 hash；以实际媒体、
  执行配置和 latent 谱系为准。禁止把不同工作流候选无意混拼。
- 查看实际执行的 motion-context trim；源头已经去过重叠就不能再
  按“接力头总有 1 秒”重复裁切。
- 源素材只读；分析写任务缓存，衍生产物写新版本目录。

### 2. 先定剪辑计划，保护剧情

- 使用帧级半开区间 `[in_frame, out_frame)`，每个保留/删除决定写原因。
  显式落实 `EDIT_NOTE.txt`，记录坏拷贝与保留拷贝，不猜注释含义。
- 首词前 0.35s / 末词后 0.5s **仅是候选点**，不是自动删除许可。
  结合分镜、动作和交出状态，先标注受保护区间，再定点。
- **有对白单元里的无对白动作同样需要保护。** v21 EP01 U04 的系鞋带、
  起身和最终反应必须保留；旧算法会把 14.17s 剪到 4.16s，是反例。
- 对齐全部期望台词，不静默丢句、不切半句；重录/重复尾段选完整一版。
- 无对白条默认保守保留，镜头切分与运动量只是审阅证据；慢动作、
  静止表演和环境底噪不等于废片。中段移除必须证明剧情不断裂。
- 计划和渲染分开。试片 runner 读取输入 manifest；旧粗剪器只在渲染后
  写 manifest，不支持改点重放，不能用于“先审后渲”的主流程。

### 3. 接缝按证据处理

- 先看缝前后画面与声音，再判断换场、同人同框、听者反应或连续动作。
  prompt 只提供候选语义，不证明实际画面和说话人。
- 默认音画同点硬切。确有声音把手、无抢话且镜头允许时再做 J/L cut；
  0.15s、0.30-0.50s 是既有实验参数，不是强制提前量。
- 不强行删除匹配在 0 帧的头，不为制造 J-cut 而跳掉有效动作。
  相似度低、景别变化或来源已裁头时，回到目检，不强求灰度匹配。
- 改音频落点后检查上一句结尾、下一句开头、口型、环境声；微淡化
  只用于合适的把手，不淡掉字头字尾，不让两句被动叠读。
- 不用混合帧/跨缝补帧掩盖生成错误；有剧情依据的换场淡出可用。
  掉帧感也要检查帧数、PTS 与解码，不能先验排除真实丢帧。
- 调色默认不做强制匹配。确有同光照跳色时小幅调整并目检肤色/夜景；
  逐通道 p5/p95、55% 力度只是旧实验，不作为所有镜头的固定滤镜。
- 人物轴线、服装、持物错误剪辑不能修好；记录坏段和替代方案。
  补生成属于另一次有成本的操作，不因进入后期就自动获准执行。

### 4. 完整包装与渲染

按后期参考执行字幕、配乐、结尾设计和样本域混音。使用审过的输入
manifest，新建 revision 目录，不覆盖旧片。计划须含与英文 cue 一一对应
的 `zh_captions`（继母包 `（）` 内通常只有英文，中文靠计划补齐）。

### 5. 交付产物（硬约定）

飞牛 `整集剪辑/EPxx/` 至少包含：

| 文件 | 要求 |
|---|---|
| `EPxx-master.mp4` | **无配乐**：对白 + 结尾 SFX only |
| `EPxx-review-en.mp4` | 含 BGM（对白避让）+ 烧录英文字幕 |
| `EPxx.en.srt` / `.en.ass` | 英文短句字幕 |
| `EPxx.zh.srt` / `.zh.ass` | **中文词轨**，与英文 cue **同一时间轴** |
| `EPxx.words.srt` | 英文 ASR 逐词（诊断用，可选归档） |
| `MUSIC_CREDITS.txt` | BGM 授权（即使 master 无乐也保留） |
| `edit_manifest.json` / `creative_plan.json` / `qc_report.json` / 自检 | 计划与证据 |

缺 `zh.*` 或 master 仍带 BGM 床，不算交付完成。旧集若要统一规格，按新管线重渲后再覆盖归档。

### 6. QC、审核与交付门禁

按 [QC 与审核](references/qc-review.md) 检查最终导出的实际文件，
不能只看 manifest 或中间 WAV。执行 agent 自检音频、字幕/视觉、剧情
节奏与结尾，记录实际检查、最终成片 hash 和剩余风险。
子 agent 审核不再是默认步骤或交付门禁，仅在用户明确要求时启用；
未启用记为 `NOT_REQUESTED`，不是审核失败或待补项，不伪造评审。

区分“技术检查通过”“可供用户审片”“用户确认发布”。改片后相关检查
与审核失效，必须对新 hash 重做。完整实时观看/听感没有做就写未做。

## 暂不自动改变生成策略

反应镜头、无对白把手、单元落在完整动作结束处，有助于未来剪辑。
但新增 B-roll、桥接生成、改用独立生成或改变默认 latent 接力，均应
作为单独提案，不在后期任务中顺手修改生成契约或重跑原始单元。
