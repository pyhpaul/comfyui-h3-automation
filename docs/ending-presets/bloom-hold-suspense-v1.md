- 登记日期：2026-10-22。

## 效果结构

**清晰末镜 → 高光扩散/泛亮/柔焦渐强 → 在泛光强态额外定格 1 秒 →
干净的 TO BE CONTINUED 尾卡。**

泛光时加入轻气流上升，进入定格时落低频重音，尾音延续到尾卡。
这不是单纯推近，也不是多重人物残影，不附加二维码或音乐署名小字。

适合信息揭露、关系反转及悬念收束；平静反击可在符合用户风格时选用。
不在最后一句未完、关键动作未完成或必须连续观察的镜头上硬定格。
原图已经严重失焦、过曝或人物边缘有缺陷时先验证，不靠该效果遮错。

## 基准时序

以下秒数相对 **6 秒概念样片**，不是 EP 的绝对时码：

| 时间 | 画面 / 声音 |
|---|---|
| 0–2.50s | 保留原有末镜运动，不额外推近 |
| 2.45–3.75s | 气流逐渐上升 |
| 2.50–3.10s | 高光泛亮、光晕与柔焦逐渐增强 |
| 3.10–3.75s | 保持强效果，画面仍沿原镜头运动 |
| 3.75–4.75s | 在上一步最后一帧额外定格 1 秒；3.75s 落低频重音 |
| 4.75–6.00s | 接 1.25 秒干净尾卡；重音尾音持续至 5.15s |

24fps 基准：剧情尾段 90 帧＋新增定格 24 帧＋尾卡 30 帧＝144 帧。
其他帧率以秒换算并检查取整，不能固定插 24 帧。尾卡沿用短淡入，不在
强泛光与尾卡之间再强套旧版六帧淡黑；本版就是在效果峰值接暗尾卡。

## 技术参数与可调项

机器可读基准见 [JSON](bloom-hold-suspense-v1.json)。

- 高光层：RGB 阈值 135，增益 2.2，高光层高斯模糊 sigma 12，与底图
  screen 混合；效果图整体柔焦 sigma 6、亮度 +0.08。
- 原图到效果图用 0.6s 线性权重渐变；强效果不包含额外 zoom 或人脸修改。
- 参数针对原生 768x1376 素材。新画幅需按视觉尺寸调整模糊半径、字幕/
  尾卡字号，检查亮部是否吞掉表情和线索，不直接盲抄像素。
- 追加定格、渐强时长、光晕/柔焦强度、声音强度可按剧情覆盖。优先
  调这些项，不再用扩大 zoom 代替本方案。
- 音效使用本地合成的滤波粉噪气流与衰减正弦低音，未使用外部音效样本。
  基准含 65Hz 主音与 130Hz 谐波；对白结束后才使用，检查小音箱可闻度。
- 样片为延长结尾，将原末 2 秒音乐无变调拉伸至 3 秒。这是样片处理，
  新 EP 优先让配乐乐句自然延长，不固定要求所有曲目按同样比例拉伸。
- 峰值限幅为 0.8FS、关闭自动补偿、启用延迟补偿；完整 EP 仍须重新
  混音/响度复测，不能拿六秒片段的 -18.87 LUFS 当整集交付目标。

资源缺失时先恢复或按本方案重新实现，不用旧粗剪器替代。
新 EP 需要适配锚点/素材、检查词尾与动作、重新 QC 并由 agent 审核。
