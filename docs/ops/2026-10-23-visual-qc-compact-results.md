# 视觉 QC 性能与压缩小样

**结论：阶段诊断、在途调度和范围复核保护已补齐。两组压缩小样耗时较低，
但模型范围判断仍不稳定，压缩不能默认替代完整工单。**

## 改动与边界

1. `cli_progress.py` 记录首事件、首图、全图、最终答案的本地到达时间；诊断日志
   不复制事件正文。没有事件回执与读完图仍无答案分开记录，不能推断供应商内部根因。
   总超时仍为 240 秒，不自动重试、不自动换模型。
2. `scheduling.py` 将“两条一组等完”改为最多两条在途、空位即补。
   先统计已观察完成的失败，再补任务；两次失败后不再提交，已经在途的等待留痕。
3. `compact.py` 生成字面原文投影，保留章节、位置和全部原指控/相同图片。
   只合并同章节完全相同的行，不把语义相近文字强行合并；完整父工单不修改。
   依赖声音的通用候选标待查，不是通过。部分输入可能不含道具尺寸等参考定义，
   缺上下文必须不可验，不能反推“原剧本未规定”。
4. `OUT_OF_SCOPE` 明确进入 `SCOPE_REVIEW`，不能自动关闭旧线索。
   景别改变本身不能用来回避原文的人物排除要求；镜头对应不明仍需范围复核。

现有 `adaptive_visual_qc.py` 主流程仍给完整工单；压缩仅由独立 pilot 显式选择。
未改原片、NAS、ASR、L0、registry、凭据或 MCP 传输；没有提交/推送 Git。

## 本地准备

同一批前三集 16U 均验证父工单、源视频和图片 hash；不重新拉取 NAS。
生成 32 份 full/compact 对照输入，图片字节与帧 ID 完全一致。
原文片段/候选 quote 均以字符偏移回查父原文，没有用摘要覆盖原文证据。

- 全部输入字符合计：166051 → 133025，减少约 20%。这是字符计数，不是实测 token 账单。
- 活跃候选 67 → 51；16 条明确需要声音的通用候选保留为待查，不是假装少了 16 个缺陷。
- 原图集合未缩减，没有更换采样档位。只小样提交，不全量请求模型。

## 两组实际对照

Cursor CLI / `grok-4.7-low`，同组图片、公共提示词及结果 schema 相同；
变量是 source 上下文的完整/投影及显式声音候选分流。每组两次调用同批运行，并发不超过 2。

| U | 完整输入字符 | 压缩输入字符 | full 耗时 | compact 耗时 |
|---|---:|---:|---:|---:|
| EP01-U04 | 13815 | 11182 | 229.370s | 194.335s |
| EP02-U03 | 8892 | 6754 | 143.471s | 103.839s |

单次观测分别低约 15% / 28%，**不是稳定速度保证，更不是等质量提速结论**。
没有多轮随机化/顺序平衡，网络、模型非确定性和输出差异仍是混杂变量。

本地时间线显示，全部图片回执到达后仍有约 76–174 秒才收到最终答案。
主要等待发生在读图之后，不能继续把全部耗时归因于逐图工具往返；
也不能把这段时间全称为纯模型计算，仍包含远端处理、输出与客户端环节。

## 契约纠正，不抹掉首轮失败

最初严格 schema 校验中，EP02-U03 compact 和 EP03-U06 compact 各报一次
`Unknown source constraint`：模型回显了已知 deferred ID，状态为 `NOT_CHECKED`、
空帧、空 quote，并未宣称检查成功。

修正后的后置验证仅允许这种已知、无证据的待查回显；未知 ID、阳性状态、帧证据、
被改写 quote 都不能被过滤。每条活跃候选仍须恰好返回一次。
原始回答及最初校验原样保留，新验证另写 `verified-comparison.json`：五份均满足新契约。
这是对状态协议的修正，不是五份视觉结论都可靠，更不表示修掉了实际画面问题。

## 实际暴露的质量问题

- EP02-U03 两个版本均正确拒绝“普通一件衬衫 = 衣柜只能有一件”的加强解读。
- **EP01-U04 两个版本都把 `Damian在镜头外。` 判为 OUT_OF_SCOPE**，认为实际宽景
  不能对应预期中景。它们都描述了末段年长男性入画，却未保留原有偏差判断。
  不能把此事单独归因于压缩：完整输入版本也出现同样解释。
- 同一幅画面上，站位、戒指可见性等细节仍有模型间/运行间波动；不投票，不宣布人审通过。
- 旧重点线索由工单和 `SCOPE_REVIEW` 保留，不因这次模型未报而关闭。
  **当前小样未达到可默认推广的质量标准。**

完整音画 L2 仍未完成；当前图片路线不能判断实际漏句、同念、说话人或口型。

## 调度优化验证

事件驱动测试验证：慢任务仍阻塞时，快任务空出的名额会启动下一条；并发峰值不超过 2；
达到失败阈值不再提交。未为了测调度再请求 16 条模型。

按上轮 16 次固定调用时长做虚拟重放：固定分组 1401.047 秒，在途调度 1275.937 秒，
差约 125 秒。这是固定时长仿真，不是新一轮实测收益；真实模型耗时会随负载改变。
