# L1 — 原分与补充线索分开

复用 `comfy-h3-dialogue-check` 的提取和评分；不另造替代评分器。

## 必留信息

- 视频/prompt hash、模型、设备、精度、VAD、word_timestamps、耗时、错误或重试。
- 原始 ASR 文本、全部时间段、原评分及评分器版本；不可为匹配剧本而改写原文。
- 名字/数字等归一化仅在单独比较视图中做，保留映射记录。
- 中译注明来自剧本或 ASR，不能标成已经听到的内容。

## 补充复核（不覆盖原分）

1. 以剧本台词为全集，对齐 ASR 的遗漏、重复、顺序差异；保留多对多关系。
2. 额外检查期望台词已覆盖后的 ASR 尾段；现评分器会忽略部分覆盖后尾段以降低幻觉误报。
3. 无对白 U 的非空转写也保留线索，不按 ASR 猜出隐藏对白。
4. ASR 缺句不等于源音轨缺句，剧本外 ASR 不等于真实多说。统一写待听音确认。
5. 可做关闭 VAD 等单变量复核，记录新旧设置；不得反复换设置直到得出想要的结果。
6. 越过源时长、跨多人台词的段级时间不直接作为剪辑点或口型精确边界。

本批校准线索：EP01-U03、EP02-U03 尾段额外 ASR；EP03-U02 电话问句未转写。
二次 ASR 同样缺句只能增加复核优先级，不能代替试听。

## 传递到 L2

以剧本 `dialogue_id` 建立逐句清单，保留无 ASR 匹配项；另建未知/额外发声区间。
严禁按 `expected_lines[i]` 与 `segments[i]` 配对：ASR 合句、拆句或漏句均会造成后续错位。
未定位的期望台词保持 `UNALIGNED`，回看全 U；不要编造起止时间。
`heard_text` 若旧 helper 用此键保存 ASR，应注明来源为 ASR，不表示人工听见。
