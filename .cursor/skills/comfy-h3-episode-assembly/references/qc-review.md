# QC、独立审核与交付

用于完整后期交付。检查实际导出文件，记录工具、输入、时码和 hash。

## 1. 门禁与当前自动化边界

| 检查 | 试片现有实现 | 执行要求 |
|---|---|---|
| 源视频、prompt、词轨身份 | runner 核对源/prompt hash；词轨绑定源 hash | 补查单元齐全、版本、候选唯一性 |
| 剪辑区间 | 帧区间边界、重叠、期望台词不被切断 | 检查动作保护和剧情交出状态 |
| 最终视频 | 帧数、完整解码、音画时长差不超 1 帧 | 检查 PTS/接缝运动，不等于已验口型 |
| 最终声音 | MP4 响度与 TP 门限；逐 U 波形锚点 | 检查听感、抢话、字头字尾 |
| 音乐时间轴 | 混音残差、cue 内外、尾卡音乐和总采样数 | 核对最终 AAC、乐句与情绪 |
| 最终台词 | 新 ASR、按序对齐、记录 token 序列比较 | 比较字段为 false 必须处理，不能仅凭退出码 |
| 黑帧/冻结 | verify 扫描剧情区，排除计划内淡出/尾卡 | 当前只记录事件；逐事件判定，不默认通过 |
| 字幕 | 台词对齐、时间重映射、部分样式约束 | 检查烧录版跨镜、两行、安全区和可读性 |
| 子 agent 审核 | 外部执行，runner 不会自动启动 | 三路独立审片，绑定同一最终 SHA256 |

旧 `scripts/assemble_episode.py` 的 `qc.json` 不具备上表完整能力，
它记录 loudness 也不是自动阈值验收；不能与试片报告混为一谈。

v3 的 verify 已重算当前 MP4 SHA256，与 ASR、已有 QC 三方比对，并在
最终 token 序列不符时阻断。旧版本只比较两份报告，不能拿旧脚本的
成功退出当作当前成片身份或对白通过证明。

试片技术门限：最终 -16 +/- 0.6 LUFS、TP <= -1 dBTP；内部渲染目标
-1.5 dBTP，不等于最终验收上限。如平台更严，更新实际渲染与验收实现，
不能只改 manifest 注释。

## 2. 状态不得混用

- 渲染成功：只是命令完成。
- 技术通过：全部相关指标有证据且达标，不能由文件存在推断。
- 可供用户审片：技术门禁与独立审核无未解决阻断项，附剩余风险。
- 发布批准：用户确认；没有完整实时音画观看时明确保留该缺项。

ASR 证明不了说话人和口型；抽帧证明不了运动流畅和完整听感；
静止镜头不自动算坏帧。报告不得用“观后感”包装未执行的实时观看。

## 3. 子 agent 审核契约

本工作流已获用户要求：做完由子 agent 审核。每路只读，不改源素材。
提供相同输入：最终 MP4 路径与 SHA256、输入/输出 manifest、字幕、
QC、音乐授权、接缝时码、此前问题清单。不要只发自己的结论给审核者。

建议三路：

1. **音频**：独立解码最终文件、响度/峰值、对白锚点、音乐 cue、
   ducking、尾卡声音；区分信号检查和实际听感。
2. **字幕/视觉**：实际烧录帧、手机宽度、文本一致、时间与换行、
   跨镜归属、面部遮挡、尾卡显隐和署名可读性。
3. **剧情/节奏**：剧情顺序、接缝动作重复、建立镜头、非对白动作、
   反应镜头、结尾情绪；检查删去内容是否丢了信息。

结尾/配乐创作审核还要回答：效果是否强化了实际悬念而非制造错误情绪，
推近是否裁掉关键人物/动作或暴露瑕疵，虚影是否误伤人脸/字幕，音效是否
盖词或形成刺耳峰值，换曲是否割裂情绪，音乐是否过满。检查新增音效/曲目
的许可与实际落点。agent 先修复阻断问题再交推荐版，不将所有选择推给用户。

每路输出实际检查的文件/hash、时间范围和方法；注明是否完整实时播放
和听音，未做写未做。问题附级别、时码、证据、建议，区分 P0/P1 阻断项
与 P2 优化项，并判断能否交用户审片，不给空泛“通过”。

汇总到 `AGENT_REVIEW.md`。修复后重算 hash，重跑受影响 QC 并让对应
审核者复核新版本；旧片审核不能背书新文件。不同工具能力要分别记录，
不能合并成虚假的“三位都完整看过”。无委派能力时明确报告缺项。

## 4. 最小交付包

- 不烧对白字幕的母版、英文烧字幕审片版；试片母版仍包含尾卡文字。
- 英文 SRT、ASS、逐词诊断轨。
- 输入剪辑计划、实际渲染 manifest、变更原因、源和输出 hash。
- `qc_report.json`、`music_timing_qc.json`、命令日志。
- `MUSIC_CREDITS.txt`、审片说明、`AGENT_REVIEW.md`。
- agent 的创作决策记录与人工可改项；实际落点/参数写入渲染 manifest，
  仅计划但未实现的效果单独标记，不能计入成片功能。
- 如获授权上传：清单、远端路径、逐文件读回 hash、发布回执。

上传不是渲染默认副作用。获准才调用发布工具；保持版本目录独立，
不覆盖源文件、旧审片或定版，不顺手迁移无关媒体。
