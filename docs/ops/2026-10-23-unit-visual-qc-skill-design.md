## 1. 目标与非目标

### 1.1 目标

用 **Cursor skill 驱动**成片（或复修候选）的多维审核：剧本结构风险 → 词面 → 同镜口型全检 →（后续）穿帮筛查 → 人定案 → 可选升级复修。

**核心原则：**

- **Skill 编排、脚本辅助**
- **自动层可给操作结论**；**最终成片仍走人审**（本流程不替代人审签字）

首要业务规则：

- **双人同念类口型审核**：剧本分析为「同镜画面内 ≥2 人且有对白」时，该 U 进入强制 L2 工单；其余不默认强制 L2。
- **L0 只描述预期同框风险，不保证实际画面**；实际媒体多人或坏例可通过人工/媒体升层进入 HIGH。
- **穿帮（L3）**：首版仅状态接口 + references；默认 `NOT_RUN`。

### 1.2 非目标

- 不用单一扫描脚本退出码代替审核结论。
- 不在无连续带声观看能力时补写 L2 实看结论（抽帧不能代替 V2）。
- 不自动重渲、不自动改 prompt（只产出工单、结案建议、复修指针）。
- 不合并 `comfy-h3-dialogue-check`；本 skill 编排调用它。
- 整集拼接/响度/字幕属 `comfy-h3-episode-assembly`。
- **不重新引入强制子 agent 审核**；由执行 agent 按规程工作，证据不够则保留待审。

## 2. 设计原则

1. Skill 是真相来源；改流程先改 skill。
2. 分层门控；高成本层只对工单命中项（及升层项）执行。
3. 自动结果可用于工单分流与阶段结论；最终成片人审兜底。
4. 复用 `prompt_source`、`human_review`、`audit_candidate`、`fix_registry`、对白报告；计划/报告必须绑定素材版本（§6）。
5. **无需专用 helper 即可开展审核**；缺少播放/试听能力时 **L2 保持未完成**，勿用抽帧冒充实看。

### 3.1 与「复修候选完整审核」的关系（必须区分）

| 场景 | 要求 |
|---|---|
| **本 skill 默认触发（生成后批次 QC）** | L0/升层得到的 HIGH → 触发该 **U 的全部对白** L2；非 HIGH 不默认强制 L2 |
| **复修登记候选定案（fix_registry STRICT/RELAXED）** | 仍遵守既有 V2：**该候选全部对白句**完整带声实看，含快速正反打等高风险结构；**本 skill 的 L0 触发策略不覆盖、不减免**复修定案要求 |

旧 V2 将「双人同框、快速正反打、画外接正脸、接力缝首句」等列为高风险，那是**复修定案范围**。本 skill 的 L0 是**批次分流**：哪些 U 在日常 QC 里必须先做口型全检。二者并存，禁止用「L0 未命中」宣称复修候选可免 V2。

## 4. 分层检查图

```text
L0 剧本同镜风险（+ 人工/媒体升层）→ 工单
L1 词面 ASR（编排 dialogue-check）
L2 同镜口型全检（HIGH 对应 U 的全部对白；V2 实看）
L3 穿帮筛查（默认 NOT_RUN）
L4 结案 / 升级复修
```

### 4.1 L0 — 剧本同镜风险

**输入**：`prompt_source.txt`（优先）或 `prompt_h3.txt`。

**逐 `▲` 提取**：`on_screen[]`、`has_dialogue`、`speaker`、`lips_lock_hint`、命中理由。

**升 `HIGH_RISK_CHORUS`（剧本路径）**：

```text
len(on_screen) >= 2  AND  has_dialogue
```

**试点模式（P1–P2，已定）**：同一批 **Strict 与 Medium 双跑**，报告中并列两套命中及各自理由，供校准。正式默认模式留待 P2 后另定；最终成片仍走人审。

**「望向 / 落到」不得合并（已定）**：

- 「A 望向 B」→ **不**证明 B 入画。
- 「镜头落到 B 脸上」→ 证明 **B 可见**，**不**证明 A 仍同框。
- 须结合镜头范围（括号机位、景别）、切镜/过肩/正反打描述判断谁在画面内。细则写在 `references/l0-chorus-risk.md`。

**灰区 `REVIEW_PARSE`（已定）**：

- **不自动**升 HIGH。
- **必须复核**；不得规定「永不升」。
- 复核后若确认多人同框、**实际媒体**出现额外人物、或命中已知坏例 → **可升 HIGH**，并记录升层原因与证据。
- **未处理完灰区不得宣布本批同镜排查完整。**

**低风险含义（已定）**：仅表示「不默认强制 L2」，**不是**「已证明无同念」。剧本写单人、成片多出人物时，须走人工/媒体升层。

**P2 校准目标（试点指标，非已成立能力承诺）**：已知坏例召回 ≥90%、明显单人误标 ≤15%；须含正常对照，报告样本数与漏报明细。

### 4.2 L1 — 词面

编排调用或复用 dialogue-check；与 L0 正交；词面 PASS 不减免 L2。报告须绑定词面所用源视频身份（§6）。

### 4.3 L2 — 口型全检

**定案范围以 U 为单位（已定）**：

- HIGH **镜头**用于**定位与触发**；触发后对该 **U 的全部对白句**做 V2 完整带声实看。
- 单镜检查结果只能证明该镜，**不得**仅凭单镜给整个候选记 STRICT。
- 若未来要缩小检查范围，须另设「局部结论」schema；首版不做。

**能力约束（已定）**：无连续播放+试听能力时，L2 状态保持 `NOT_DONE` / `INCOMPLETE`；禁止用抽帧补写实看结论。

**P1 不做 L2 定案（已定）**：P1 只交 skill + 一集 `plan`；标记 **「风险排查完成、说话人未定案」**（阶段范围）。最终成片仍走人审。

### 4.4 L3 — 穿帮（已定）

- 仅 `references/l3-blooper-screen.md` + 状态接口。
- 默认 **`NOT_RUN`**。
- 不引入强制抽帧全量审片。
- 未执行时结案写明「穿帮未检查」。

### 4.5 L4 — 结案

换候选/重渲后旧报告失效（§6）。阶段结论可写；最终成片人审兜底。

## 5. Agent 工作流（摘要）

见 skill `SKILL.md` 检查清单。P1 停在步骤：L0 双跑 + 写 plan + 版本绑定 + 状态标记；不跑完 L2。

## 6. 计划 / 报告必须绑定的版本信息（已定）

每份 `plan` / `report` 至少包含：

- 源视频 SHA256（按 U；无成片则标明 `media: absent`）
- prompt SHA256（所用 prompt 文件路径 + hash）
- 候选/批次版本标识（目录名、job id、feiniu 路径等）
- 规则版本（skill 名 + 文档/git 修订说明或日期）
- 解析模式：`strict` / `medium` 各自结果
- 每层状态、检查范围、证据指针
- 词面报告路径及其与源视频的绑定（若已跑 L1）

旧 hash 不匹配时，禁止沿用旧结论背书新文件。

## 7. 复修衔接

同前：同念 → 闭嘴锁+种子；肢体/多物 → 种子+硬锁；词面可剪 → EDIT_NOTE。  
`defect_class` / `source_layer` / `plan_shot_id` / `promote_reason`（灰区或媒体升层）建议写入登记。

## 8. Helper 脚本

后置；服从 skill schema。P1 不要求新脚本；允许 agent 手工解析或临时一次性命令。
